## 这份报告证明了什么

它把项目 README 里那几条**设计承诺**变成了可测量的指标：

- 「三级匹配」→ 第 ①②③ 级各自有没有按预期命中
- 「必须调飞猪查真实数据」→ 需要工具的用例里，事件流有没有真的出现工具调用
- 「查不到必须如实告知，禁止补数据」→ 兜底类用例里有没有出现诚实的「没有 / 暂无」表述
- 「缺三要素必须追问」→ 信息不全的用例里有没有追问出发地/时间/预算
- 「不代下单」→ 让它代付款时有没有拒绝并给出跳转链接

**局限**：本报告评测的是**行为**，不是**数据准确性**。数据准确性由 `demo/verification-report.md` 逐条核验。
