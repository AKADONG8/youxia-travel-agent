# 演示视频脚本 · 2 分 30 秒

> **用途**：录制参赛演示视频时对着念的逐字旁白稿。
> **工具**：Windows 自带 `Win + G`（Xbox Game Bar）即可录屏，零安装。字幕用剪映 / CapCut 自动识别生成。
> **总时长**：约 2 分 30 秒，旁白约 620 字（中文语速 ≈ 250 字/分钟）。

---

## 录制前检查清单

- [ ] **新开一个百炼会话**（旧会话已归档，`terminated` 终态，不能再交互）

- [ ] 分辨率调到 1920×1080，浏览器缩放 100%，关掉无关标签页
- [ ] 提前把要输入的三句话存在记事本里，避免录制时打字卡顿

## 分镜与逐字旁白

### 0:00 – 0:15 ｜ 开场

**画面**：标题卡（黑底白字或仓库 README 顶部），然后切到百炼控制台的会话界面。

**旁白（逐字）**

> 你玩什么游戏，决定你去哪座城。
>
> 这是「游侠出行」——一个把玩家的游戏口味，转成可执行旅程的 AI 旅行智能体。
> 它跑在阿里云百炼的托管智能体上，数据来自飞猪官方技能。

**备注**：语速放慢，这句 slogan 要让评委记住。

---

### 0:15 – 0:40 ｜ 识别小众游戏，不给通用攻略

**画面**：在输入框输入第一句话，回车。展示智能体的开场回复。

**输入**

```
我玩一个很冷门的像素风独立游戏，周末想去成都玩，但不知道玩啥
```

**旁白（逐字）**

> 我们先给一个最难的情况：一个冷门游戏的玩家。
>
> 注意它没有直接甩一份成都景点列表。它先识别出「小众游戏」这个信号，走知识库的三级兜底——精确映射、类型风格兜底、反问引导。同时它去查成都这周末到底有什么活动。
>
> 左边这个事件面板里，能看到它在真实调用飞猪的工具。

**备注**：鼠标可以指一下左侧的工具调用记录，让"真实调用"这件事被看见。

---

### 0:40 – 1:00 ｜ 推荐逻辑解释

**画面**：输入第二、三句话，展示推荐逻辑回复。

**输入**

```
重庆出发，周五走周日回，预算 1200 左右
```

```
A 吧，我平时也爱看比赛，虽然自己玩的是冷门游戏
```

**旁白（逐字）**

> 它把「游戏口味」和「体验意图」拆开处理：游戏口味走小众兜底，体验意图走竞技线。
>
> 然后它解释了为什么推荐 A 方案而不是 B，还把 1200 的预算拆开了。
>
> 这一步是通用攻略给不出的——它会告诉你取舍在哪。

**备注**：这是"创新点"的落点，语速可以稍慢。

---

### 1:00 – 1:25 ｜ 真实数据

**画面**：滚动展示车次和酒店的真实返回数据。

**旁白（逐字）**

> 接下来是数据。
>
> D49 八十五块、Z333 五十块五、T8804 五十块五——这些车次和票价都是飞猪实时返回的。
>
> 酒店也一样：雷泽电竞酒店二十九块一晚，758 电竞酒店五十五块一晚。每个推荐后面都带飞猪的跳转链接，可以直接下单。

**备注**：念价格时可以稍微停顿，让数字被听清。

---

### 1:25 – 1:50 ｜ 无赛事兜底（★ 最关键的一段）

**画面**：展示东安湖查询结果 —— 场馆信息 + "无赛事"的兜底回复。

**输入**

```
东安湖体育公园咋样？新场馆看比赛氛围好
```

**旁白（逐字）**

> 这一段我想重点说。
>
> 它确认了东安湖体育公园是 2021 年大运会的主场馆、四万个座位、在龙泉驿区。然后它去查飞猪这周末东安湖的赛事——结果是，没有。
>
> 它没有编一个赛事出来。它说：老板，跟你说个实话，本周末确实没有可预订的赛事门票，我给你换三套方案。
>
> 整个演示里，这个兜底真实触发过两次。

**备注**：**这一段是整条视频最有说服力的地方，不要剪掉。** 编数据的人不会给自己安排"查不到"的剧情。

---

### 1:50 – 2:10 ｜ 主动纠错（数据真实性铁证）

**画面**：输入 Z587 的问题，展示智能体纠正车次的回复。

**输入**

```
对了，去程有没有 Z 字头的直达火车，Z587 这种？
```

**旁白（逐字）**

> 再看一个细节。
>
> 用户问有没有 Z587 这种车次。它查完返回的是 Z333 和 Z588，然后主动告诉用户：Z587 方向反了。
>
> 如果这些价格是模型编的，它不会去纠正用户说的车次号。这个纠错行为本身，就是数据来自真实查询的证据。

**备注**：这一段的逻辑链要讲清楚——"纠错"→"证明非编造"。

---

### 2:10 – 2:30 ｜ 收尾

**画面**：展示最终行程单，然后切到仓库 README 页。

**输入**

```
行，就按电竞开黑版来，整体帮我收个尾吧
```

**旁白（逐字）**

> 最后它生成一份完整行程单：三天，总花费大概八百五，全部带预订链接。
>
> 游侠出行的核心不是一张「游戏名对景点」的对照表。它是从你游戏里的体验偏好出发，理解你真正想要的感觉，再用飞猪的真实供给把它落成一段能执行的旅程。
>
> 你玩的游戏冷门、这周没有赛事——照样给你一场氛围拉满的远征。

**备注**：最后一句是定位句，配一个收尾的停顿。

## 字幕建议

用剪映 / CapCut 的「自动识别字幕」生成后，重点核对这几处：

| 易错词 | 正确写法 |
|---|---|
| 雷泽 | 雷泽（不是"雷则"） |
| 东安湖 | 东安湖（不是"东岸湖"） |
| 龙泉驿 | 龙泉驿（不是"龙泉一"） |
| 飞猪 | 飞猪（不是"飞竹"） |
| Z333 / Z588 / D49 / T8804 | 字母 + 数字，注意大小写 |
| 游侠出行 | 统一为"游侠出行" |
